# Screenshots

This document tracks visual references for the current UI state.

## Current status

The documented M6 screenshot is now checked in at:

- [`docs/screenshots/m6-main-window.png`](screenshots/m6-main-window.png)

## Recommended capture target

Capture the main window when it shows:

- left and right panes with tabs enabled
- the inline filter fields above the panes
- the file-type icon column
- a selected file in one pane and drag-and-drop target state in the other
- the quick preview dialog available via `F3`

## How to capture

Suggested approach:

1. Start the app from `ui-javafx`.
2. Open a representative local directory structure.
3. Arrange the panes so both tabs and filters are visible.
4. Capture the window with a screenshot tool on Windows.
5. Store the image under `docs/screenshots/` and link it from `README.md`.

## Placeholder policy

If the UI changes significantly, capture a new image and replace the existing PNG so the docs stay current.
